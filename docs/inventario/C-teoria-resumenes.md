## 6. Notacion/convenciones recurrentes
- Jacobiano: |J(x,y / u,v)| = |dx/du dy/dv - ...|, factor en valor absoluto; esfericas r^2 sen(phi) (E14 p12-13; Rocha 11_CC p1; Modelo P2 teorico p.3).
- Integral de superficie: dσ y vector normal n (cos α, cos β, cos γ); dσ = dxdy/cos γ (E14 p30-31; Monllor 07 p9-14). Flujo = ∬ F·n dσ.
- Rotor: "rot F = ∇×F" por determinante i,j,k (E14 p19, Monllor 07 p5); divergencia "div F = ∇·F" (E14 p18). Gradiente "grad f" y ∇f.
- Curvilinea: ∫_L P dx + Q dy, "∮" con "sentido positivo = antihorario" (E14 p22; resumen-alumno p16; Monllor 06); Green con ∂Q/∂x - ∂P/∂y; independencia de trayectoria si ∂P/∂y = ∂Q/∂x; función potencial u(x,y) (E14 p25-29).
- Stokes: ∬ rot F·n dσ = ∮ F·ds (E14 p31); T. Divergencia ∭ div F dv = ∬ F·n dσ (E14 p33).
- EDO: "Solución General / Particular", lineal con y=u·v (resumen-alumno p23-24; E14 p37-38; Rocha usa fórmula cerrada y=e^{-∫P}[∫Q e^{∫P}+C]); Bernoulli z=y^{1-n}; exactas φ(x,y)=C; 2do orden: Y_GNH = Y_GH + Y_P (E14), "y=yh+yp" (Rocha 15), raíces m1,m2 (E14) vs k1,k2 (resumen-alumno p28) vs K (Resumen teorico).
- resumen-alumno usa "f(x; y)" con punto y coma; E14 usa coma. Fourier: ω0, c_n con e^{i n ω0 t}, funciones pares/impares (E14 p50-56).
- EDP: clasificación por B²-4AC (<0 elíptica/Laplace, =0 parabólica/calor, >0 hiperbólica/ondas) (E14 p58).
